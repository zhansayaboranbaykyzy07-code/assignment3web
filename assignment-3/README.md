## Project Overview
This project focuses on building responsive web applications using CSS Media Queries and the Bootstrap 5 Grid System. The objective is to design layouts that automatically adjust across mobile, tablet, and desktop viewports, combining adaptive typography, flexible grid structures, collapsible navigation menus, and a complete responsive portfolio page.

## Summary of Work Process
1. **Initial Setup:** Configured base HTML structure with Bootstrap 5 CDN and responsive meta viewport tags.
2. **Custom Breakpoints:** Wrote custom CSS media queries for font scaling (`Task 0`) and responsive Flexbox layout behavior (`Task 1`).
3. **Bootstrap Grid & Components:** Built responsive layouts using Bootstrap 12-column grid classes (`Task 2`) and added a collapsible navigation menu (`Task 3`).
4. **Portfolio Assembly:** Combined media queries and Bootstrap grid utilities into a clean, modern portfolio landing page (`Task 4`).
5. **Testing & Deployment:** Verified layout responsiveness across mobile, tablet, and desktop screen widths, generated documentation, and pushed the repository to GitHub.
